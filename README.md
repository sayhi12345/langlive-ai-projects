## 發布

GitHub Pages 從 `main` 分支的根目錄發布。將更新推送至 `main` 後，GitHub 會自動重新部署。

此專案為靜態 HTML、CSS 與 JavaScript，無須安裝套件或執行建置。`.nojekyll` 停用 Jekyll 處理，直接發布靜態檔案。
