# 浪LIVE AI 專案 2026

[開啟線上簡報](https://sayhi12345.github.io/langlive-ai-projects/)

完整版共 77 頁，包含浪小蝦（12 頁）、AI 客服（16 頁）、AI 虛擬主播（13 頁）、EDEN AI（26 頁）與直播視覺 AI（10 頁）。

以瀏覽器開啟 `index.html` 即可使用。各簡報支援左右換頁、全螢幕與 Q&A，圖片與字型隨網站提供；YouTube 影片及外部下載連結需要網路。

## 發布

GitHub Pages 從 `main` 分支的根目錄發布。將更新推送至 `main` 後，GitHub 會自動重新部署。

此專案為靜態 HTML、CSS 與 JavaScript，無須安裝套件或執行建置。`.nojekyll` 停用 Jekyll 處理，直接發布靜態檔案。

## 直播視覺 AI

由「直播AI應用_2025」第 7–11、13–16 頁轉為 HTML：10 頁（含 Q&A），保留 6 支 YouTube 與 1 支 Google Drive demo。圖解以既有簡報風格重繪；手機數據為原稿歷史範例。來源與影片對照見 assets/vision/source-manifest.json。
